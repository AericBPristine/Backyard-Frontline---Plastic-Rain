# Backyard-Frontline---Plastic-Rain
Backyard Frontline is a 3D browser defense game starring plastic army men. Defend the Green outpost against five waves of Tans. Ride a mortar round over the ridge to scout, or switch to the forward observer and scan the field with binoculars.

## Run from source

Open `project.godot` in Godot 4.5.1 and press F6 or F5 to run. Install Godot's matching export templates to build the Windows release with the **Windows Desktop** export preset.

## Controls

- **A/D** turn the gunner's view and **W/S** adjust elevation. **Space** fires.
- **C** switches shell camera mode. Either mouse button leaves the shell view.
- **O** switches between the gunner and observer. **P** switches between first and third person.
- As the observer, move with **WASD** and look with the mouse. Right-click raises binoculars and the mouse wheel zooms.
- **Esc** opens the pause menu.
